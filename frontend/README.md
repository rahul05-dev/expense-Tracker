# Expense Tracker Flutter app

This is the Flutter client for the Expense Tracker full-stack project. Its
source code is in `lib/`, tests are in `test/`, and platform-specific projects
are in `android/`, `web/`, and `windows/`.

For backend configuration, API setup, and instructions for running the complete
app, see the [project README](../README.md).

To install Flutter dependencies and run the client from this directory:

```powershell
flutter pub get
flutter run
```
